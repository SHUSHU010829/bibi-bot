# 逼逼機器人 — 新玩法腦力激盪

> 紀錄日期：2026-06-04
> 背景：`PLAN_INTEGRATED.md` 主企劃只剩 Phase S3 技能樹未實作，本文件收錄其餘可能的新玩法方向。
> 用途：腦力激盪存檔，待挑出方向後再展開為完整 Phase 規劃。

## 設計原則

- **跟現有系統互補**，給既有資產（魚、礦、農作、buff、公會、稱號）新用途
- **跨系統串接** 優先，避免另起爐灶
- **config 驅動**、**buff 走 `buffResolver`**、**符合 `CLAUDE.md` 七項 UX 檢查**

---

## 既有系統盤點（避免重複造輪子）

- 生產線：挖礦 / 釣魚 / 農場 / 打工
- 戰鬥：地下城 / 決鬥 / BOSS 共鬥
- 經濟：金幣 / 拍賣 / 市集 / 物物交換 / 股市 / 樂透 / 抖內 / 稱號 / 救濟金
- 社群：公會（成員 / 庫藏 / 週任務 / 共享 buff）
- 賭場：21 點 / Hi-Lo / Keno / 輪盤 / Crash / 射龍門 / 德撲 / 賽馬 / 拉霸（Jackpot）
- 環境：oreMarket 每日市價 / 限時活動框架 / weather 查詢（未連動玩法）

## 🐾 A. 養成 / 收集類

### A1. 寵物 / 夥伴系統 ⭐⭐⭐

玩家孵蛋 → 養成 → 出戰提供 buff。蛋從 BOSS / 釣魚 / 農場掉。
親密度、飢餓度、等級三條軸；用魚 / 作物餵食（**消化生產線過剩產出**）。
進化、皮膚、限定品種（抖內 / 活動）。
**接點**：`buffResolver` 加 `pet` 來源、weighted random 掉蛋。
**預估**：5–7 天　**亮點**：跨系統消費、最強留存。

### A2. 圖鑑 / 百科系統 ⭐⭐

首次獲得某物（魚、礦、作物、寵物）→ 解鎖圖鑑頁，全收集 → 解鎖稱號 + 隱藏 buff。
**接點**：在既有掉落 hook 寫入 `UserCodex`。
**預估**：2–3 天　**亮點**：純收集成就感、零平衡風險、做完就是長期任務牆。

### A3. 守護神 / 信仰系統 ⭐⭐

玩家選擇信仰（火 / 水 / 土 / 風 / 光 / 暗），每神不同 buff。
信徒越多 → 神力越強 → buff 越大（鼓勵拉新）。
神之間相剋（對戰時火 vs 水加成）。
**接點**：`buffResolver`、決鬥 / BOSS 接戰前讀信仰。
**預估**：4–5 天　**亮點**：陣營感、社群分群、月度信徒大戰。

### A4. 星座 / 占星系統 ⭐

玩家設定生日 → 自動分配星座 → 對應月份是「本命月」，本命月所有獎勵 +10%。
12 星座輪流，每月有 1/12 的人受惠。
**接點**：`UserSettings` 加 birthday、buffResolver 讀。
**預估**：1–2 天　**亮點**：極輕量、增加「個人化」儀式感。

## 🌦️ B. 環境 / 隨機事件類

### B1. 天氣 / 季節系統 ⭐⭐⭐

每日 00:00 seeded random 決定天氣（晴 / 雨 / 霧 / 雪 / 暴雨）。
影響各生產線（雨天釣魚 +30%、霧天 BOSS 反擊 +10%…）。
四季影響天氣機率分布；雪季限定「冰晶礦」。
**接點**：同 `oreMarket` 排程模式、`buffResolver` 加 `weather` 來源。
**預估**：2–3 天　**亮點**：低成本高 ROI、玩家養成早上查天氣的習慣。

### B2. 占卜 / 每日運勢 ⭐

每日抽塔羅，當日 buff/debuff，連續大吉解稱號「天選之人」。
**接點**：`activeBuffs` 一日效。
**預估**：1–2 天　**亮點**：每日回流、儀式感。

### B3. 神祕黑市 ⭐⭐

每日隨機 1 小時開放，賣稀有道具，10% 被查緝風險（罰幣 + 沒收）。
**接點**：新 collection `BlackMarketSchedule`。
**預估**：3–4 天　**亮點**：驚喜感、稀有道具流通。

### B4. 季節祭典 / 祭壇 ⭐⭐

玩家**集體**貢獻特定物品給祭壇（如全伺服器貢獻 100 條鯊魚），解鎖全員 buff。
**接點**：限時活動框架延伸、玩家驅動而非系統驅動。
**預估**：3–4 天　**亮點**：強社群協作、訊號式玩法。

## 🗺️ C. 探險 / 冒險類

### C1. 冒險探險 / 隨機事件 ⭐⭐⭐

text-based choice adventure。森林 / 廢墟 / 深海 3 個場景，每場 3–5 個 node。
事件樹 JSON 定義，可組隊（公會），消耗體力。
**接點**：共用 dungeon 戰鬥引擎、stamina。
**預估**：5–7 天框架 + 每場景 1–2 天　**亮點**：補目前敘事性玩法的缺口。

### C2. 遺跡考古 / 限時 dig site ⭐⭐

每週限定考古點，全伺服器集體挖掘，每人有限次數，集體進度條解鎖文物。
文物可放小屋 / 高價賣。
**接點**：複用挖礦 + 限時活動框架。
**預估**：3–4 天　**亮點**：合作型、限時話題。

### C3. 密室逃脫 / 合作解謎 ⭐

每週新謎題，公會合作解 5 題（線索分散在每位成員手上），全解出寶箱。
**接點**：複用公會、quest。
**預估**：4–5 天　**亮點**：強迫成員互動、推坑公會。

### C4. 公會 BOSS（限會員） ⭐⭐

公會內部 BOSS，公會等級越高 BOSS 越強、獎勵越好。
給「不夠人多打全服 BOSS」的小公會也能享 BOSS 體驗。
**接點**：複用 `bossEngine`，加 scope = guild。
**預估**：3–4 天　**亮點**：補小公會體驗、公會凝聚。

## ⚔️ D. PvP / 社群互動類

### D1. 公會 vs 公會 領地戰（賽季制） ⭐⭐

6–10 個地點，公會每週日 21:00 開戰、佔領者享 1 週 buff，4 週一賽季。
攻擊力 = 全會員當週活躍度總和。
**接點**：複用公會、BOSS 排程。
**預估**：5–7 天　**亮點**：高活躍公會的新目標。

### D2. 盜賊 / 偷竊 PvP ⭐⭐

每日 1 次偷竊機會，成功偷幣、失敗被通緝（其他人可追捕領賞）。
**接點**：新 collection `WantedList`、複用 coin。
**預估**：3–4 天　**亮點**：高戲劇張力、社群話題（「XX 又被通緝了！」）。

### D3. 公會結盟 / 外交系統 ⭐

公會可結盟，盟友間轉帳免手續費 / 共同領地戰。
**接點**：搭配 D1 領地戰。
**預估**：2–3 天　**亮點**：政治外交味。

### D4. 撲克 / Bingo 錦標賽 ⭐

既有德撲擴成週末 MTT，報名費 → 獎池 → 名次排行。
**接點**：複用 `pokerOpen`。
**預估**：3–4 天　**亮點**：賭場深度玩家的新挑戰。

### D5. 料理大戰 ⭐⭐

玩家提交料理（食材組合），全伺服器投票，冠軍進名菜館 + 限定稱號。
**接點**：複用 fishing/cook + voting。
**預估**：3–4 天　**亮點**：創意 + 投票互動、強社交。

## 💰 E. 經濟 / 投資類

### E1. 神祕拍賣 / 盲拍 ⭐

物品資訊隱藏(只顯示稀有度)，盲投出價，開標日揭曉。
**接點**：複用拍賣行框架。
**預估**：2–3 天　**亮點**：愛賭一把的玩家、稀有物高溢價。

### E2. 預言 / 衍生性金融 ⭐

用幣鎖定明日礦石 / 股票價格方向，猜對獲利、猜錯扣幣。
**接點**：oreMarket / stock 已有歷史資料。
**預估**：2–3 天　**亮點**：給愛分析的玩家、再加一層市場資訊深度。

### E3. 賽季通行證 ⭐⭐⭐

90 天一賽季，免費 + 進階通行證（抖內 / 公會貢獻 / 連簽達成換）。
每賽季 30 個任務，獎勵獨家稱號、寵物皮膚、家具、限定外觀。
**接點**：複用 quest、抖內 perks、新 `SeasonPass` collection。
**預估**：5–7 天　**亮點**：營運級留存武器、把零散獎勵打包成「賽季敘事」。

### E4. 商業帝國 / 開店系統 ⭐

玩家可投資頻道內「店面」（咖啡店、酒吧、商店），其他玩家消費老闆抽成。
**接點**：複用 shop。
**預估**：6–8 天　**亮點**：模擬經營深度玩家、商業生態。

## 🛠️ F. 生產 / 製造類

### F1. 個人小屋 / 收藏館 ⭐⭐

4×4 格子放家具、展示稀有收藏，家具加 buff，可訪問他人小屋按讚送幣。
**接點**：複用 inventory + 新 `UserHouse` collection。
**預估**：5–7 天　**亮點**：「擁有 / 炫耀」需求、稀有物展示出口。

### F2. 領地建造 / 工程系統 ⭐⭐

用礦石建設施（鐵爐合成 +5% / 風車農場 +10% / 燈塔釣魚 +5%）。
個人或公會擁有，公會設施全員共享。
**接點**：複用礦石消費出口、buffResolver。
**預估**：5–6 天　**亮點**：礦石長期消費出口、公會升級新方向。

### F3. 動物畜牧（農場進階） ⭐⭐

養雞 / 鴨 / 牛 / 羊，每日產蛋 / 奶 / 毛，飼料 = 玉米（接農場）。
產出用於合成料理 / 賣錢。
**接點**：複用 farm、food/cook。
**預估**：4–5 天　**亮點**：農場有第二層、玉米有用途。

### F4. 鍊金術 / 消耗道具製造 ⭐⭐

用礦 + 魚 + 作物合成消耗藥水：隱形（避免被決鬥挑戰 1 天）、體力、幸運、傳送（跳場景）。
**接點**：複用 craft 系統、buffResolver。
**預估**：3–4 天　**亮點**：跨生產線整合、補「主動消耗品」缺口。

### F5. 市集擺攤節（週末活動） ⭐

每週末開放限量 20 攤位（先搶先贏），玩家擺攤賣道具。
攤位裝飾影響「人氣」，人氣越高賣得越快。
**接點**：複用 market、活動框架。
**預估**：3–4 天　**亮點**：週末例行活動、擺攤位身份。

## 🎓 G. 身份 / 職業類

### G1. Phase S3 技能樹 ⭐⭐

原企劃唯一未做 Phase。三線（採掘 / 戰鬥 / 商業）×5 技能，每升等 1 點，可重置。
詳見 `PLAN_INTEGRATED.md` Phase S3 章節。
**預估**：4–6 天　**亮點**：玩家自選發展方向。

### G2. 轉職 / 職業系統 ⭐⭐

與技能樹差異化 — 是「身份」而非「點數」。
礦工 / 漁夫 / 農夫 / 騎士 / 商人 / 學者，每職業獨家指令 + buff。
每季可轉職一次。
**接點**：`UserSettings`、buffResolver、條件式指令。
**預估**：4–5 天　**亮點**：身份感、與技能樹可疊加。

### G3. 角色裝扮 / 時裝系統 ⭐

玩家形象（影響 profile card），用幣 / 抖內 / 公會等級解鎖。
**接點**：複用 profile。
**預估**：3–4 天　**亮點**：純外觀、抖內出口。

## 🎲 H. 輕量回流類

### H1. 每日小遊戲牆 ⭐

週一到日各一個小遊戲（猜數字、剪刀石頭布、成語接龍、心算…），全週達成大獎。
**接點**：新獨立小指令群。
**預估**：3–4 天（含 7 個遊戲）　**亮點**：每日回流動機、輕量。

偵測到實況主開台 → 觸發限定 BOSS / 副本，加倍經驗。
**接點**：複用 twitch、boss 模組。
**預估**：2–3 天　**亮點**：拉直播觀眾進 Discord。

## 🎯 主軸推薦組合

### α 留存組合（10–12 天）— 最大化 DAU

**A1 寵物 + B1 天氣 + A4 星座**
每天都有理由回來：餵寵物、看天氣、確認本命月。

### β 內容深化（10–14 天）— 給高活躍玩家挑戰

**C1 冒險探險 + D1 公會領地戰**
補敘事缺口、給公會新目標。

### γ 營運型（10–14 天）— 拉抖內 + 賽季敘事

**E3 賽季通行證 + A1 寵物 + G3 時裝**
通行證打包散獎勵、寵物 / 時裝作為高階獎勵。

### δ 輕量先試水（5–7 天）— 確認方向再加碼

**B1 天氣 + A2 圖鑑 + A4 星座**
三個都低風險、可快速上線，看數據再決定下一步。

## 通用驗收清單（任何提案實作時）

- `node src/index.js` 啟動 bot 無錯誤
- 新指令出現在 slash command 面板、執行 UX 符合 `CLAUDE.md` 七項檢查
- 新 collection 在 `connectDb.js` 註冊、索引建好（unique / TTL）
- 新 buff 來源在 `/加成` 指令顯示區塊出現
- config 駐留 `src/config/`，不寫死數值
- 按鈕 owner 驗證、Container 錯誤訊息、ephemeral 一致性
