> **前置需求**：eventBus 地基、既有 Phase 4 地下城 ✅
> **預估時間**：5–7 天
> **定位**：副本系統 2.0 — 從單回合骰子升級為多回合 HP 戰鬥；作為 Phase H 寵物部分 buff（救命阿伯失敗保體力、黑曜霸主戰後 HP +50%、寵物協戰）的依賴
>
> **開發順序**：本 Phase **先於 Phase H 寵物**，因為部分寵物 buff 直接讀取本 Phase 新增的欄位與 hook。

### 核心改造

| 維度 | 既有（Phase 4） | 進階版（Phase H+） |
|---|---|---|
| 戰鬥判定 | binary 勝率（`ATK ÷ 怪物HP`）骰一次 | 多回合 HP 對打、後端模擬整場 |
| 玩家屬性 | 武器 ATK + 暴擊 | + **HP**（自然回復）+ **DEF**（武器副屬性 + buff）|
| 怪物 | 7 種固定，HP 60–280 隨機 | 7 種按樓層分配 + **ATK 屬性** + **技能**（中毒 / 暈眩等）|
| 樓層 / 副本 | 無 | **1F–5F 樓層** + **3 種副本主題**（礦坑 / 廢墟 / 冰窟）|
| 結果呈現 | 單行勝負 | **戰鬥日誌**（多回合演進，一次回傳）|

關鍵設計：**戰鬥多回合，互動仍單次**。後端跑完整場戰鬥，前端用 ContainerBuilder 呈現戰鬥日誌 + 結算 — 不變 Discord 互動次數。

### 戰鬥引擎（HP 對打）

```
每回合流程（後端模擬）：
1. 玩家攻擊 → damage = playerAtk × (1 + critBonus) − monsterDef
2. 怪物 HP −= damage
3. 怪物 HP ≤ 0 → break（勝利）
4. 怪物攻擊 → damage = monsterAtk × statusEffectMult − playerDef
5. 玩家 HP −= damage
6. 玩家 HP ≤ 0 → break（失敗）
7. 結算狀態效果 tick（中毒扣血、護甲倒數）
8. 寵物協戰判定（依寵物類型機率觸發）
9. 下一回合

最多 20 回合上限 → 平局視同失敗（避免無限循環）
```

戰鬥日誌（玩家看到的訊息）：

```
🗡️ 第 1 回合：你揮砍洞窟蝙蝠 → 28 傷害（暴擊！）
🦇 蝙蝠尖叫反咬 → 12 傷害（你 HP 88/100）
🐶 救命阿伯吠叫 → 回復 5 HP（你 HP 93/100）

🗡️ 第 2 回合：你揮砍 → 25 傷害
🐍 蝙蝠注入毒液 → 你陷入中毒（2 回合）

🗡️ 第 3 回合：你揮砍 → 27 傷害（致命一擊！）

✅ 勝利！剩餘 HP：80/100、體力 −1
🎁 戰利品：💎 鑽石 ×1、🪙 +450 幣
```

#### 戰鬥機制（盾牌相關）

**v1 上線（鐵盾 / 鋼盾）**：

**1. DEF 疊加（武器副屬 + 盾 + buff）**
```
總 DEF = weaponDef + shieldDef + foodBuff + petBuff
受傷害 = max(怪物 ATK − 總 DEF, 1)   // 最少受 1 傷害
```

**2. 格擋判定**
- 每回合**受擊前**判定 `blockRate`
- 成功格擋 → 本次傷害 **×0.5**、戰鬥日誌標「🛡️ 格擋！」
- 失敗 → 正常結算（仍有 DEF 減傷）

**v2 預留 hook（戰鬥引擎先寫好介面，未開放時回 0）**：

**3. 反射（v2 黃金盾起）**
- 受擊後判定 `reflectRate`
- 命中 → 對怪物造成「**收到傷害 ÷ 3**」反彈傷害
- 戰鬥日誌：「✨ 盾光反射！對怪物造成 X 反彈傷害」
- 反射可以擊殺怪物（並列入擊殺判定）

**4. 異常抗性（v2 傳說盾）**
- 免疫**中毒 / 燃燒 / 麻痺**三種狀態（暈眩 / 護甲不在範圍）
- 戰鬥日誌：「🔥 傳說盾光輝抵擋了中毒！」

#### 盾牌耐久規則（觸發式磨損）

**邏輯**：盾擋了才磨損 — 戰鬥本身不扣耐久，僅在**觸發格擋 / 反射**時扣。

| 情況 | 盾耐久 |
|---|---|
| 進場（任何樓層 1F-5F）| **0**（不像劍按樓層扣）|
| 戰鬥中**每次成功格擋** | **−1** |
| 戰鬥中**每次觸發反射**（v2 黃金盾起）| **−1** |
| 一場戰鬥**封頂消耗** | 5 次（1F-5F 一般）/ 8 次（mini-BOSS）|
| 戰鬥失敗 / 逃離 | 不額外扣（看當場格擋次數）|

> 與劍的差異：劍按樓層階梯扣（高樓層耗劍快），盾按戰況扣（被打多就耗盾）。
> 兩者互補：劍重「進場成本」、盾重「戰況觸發」。

#### 盾耐久消耗試算

每場戰鬥玩家**被攻擊次數**估算：

| 樓層 | 平均回合 | 被攻擊次數 | 鐵盾格擋（25%）| 鋼盾格擋（30%）|
|---|---|---|---|---|
| 1F | 4 | 4 | 1.0 次 | 1.2 次 |
| 3F | 7 | 7 | 1.75 次 | 2.1 次 |
| 5F | 12 | 12 | 3.0 次 | 3.6 次 |
| mini-BOSS（封頂 5/8）| 17 | 17 | 4.25 次 | 5.1 次（封頂壓制）|

平均盾耐久消耗 / 場：

| 樓層 | 鐵盾（50 耐久）| 鋼盾（60 耐久）|
|---|---|---|
| 1F 純跑 | 50 場 | 50 場 |
| 3F 純跑 | 28 場 | 28 場 |
| 5F 純跑 | 16 場 | 16 場 |
| mini-BOSS 連跑（封頂壓制）| 10 場 | **8 場** |

> mini-BOSS 鋼盾比鐵盾還快壞，因為封頂限制下高格擋率優勢被吃。
> **這是合理的** — mini-BOSS 是修盾的儀式，鼓勵玩家戰前先準備。

#### 盾耐久歸零後

- 進場仍可（不阻擋戰鬥）
- 戰鬥中**所有格擋 / 反射判定自動失敗**（DEF 仍生效，盾還在身上但破損）
- 戰鬥日誌每場開頭提示一次：「⚠️ 你的盾已破損，無法格擋！」

#### 修復機制

- 既有「磨鎬石」**改名「磨石」**，通用修復**武器 + 盾牌**
- 修復公式不變（一塊磨石回滿一件裝備、max −10）
- 武器 / 盾兩者**獨立耐久**，分開修復
- 兩者都歸零仍可進場，但 DEF / 格擋 / 反射全失效

- 回復速度不變（每小時 +1）

### 武器耐久規則（為什麼按樓層而非回合）

- ✅ **按樓層扣**：直觀、與體力規則對稱、好記
- ❌ **不按回合扣**：戰鬥多回合是「後端模擬」，玩家只點一次，按回合扣會讓玩家無感且容易誤解
- ⚔️ **暴擊不額外扣**（玩家獎勵）
- 💀 **失敗仍扣**（風險不變）
- 🛠️ **維修工具**回滿（既有機制保留）
- 💎 **武器耐久歸零**：仍可進場，但戰鬥力降為「拳頭」級（既有降級邏輯保留）
- 🐉 **mini-BOSS −4 耐久**：高難度高消耗，逼玩家在打 mini-BOSS 前先維修，建立「儀式感」
- ⚠️ **建議同步調整 `dungeon.json`**：傳說劍耐久從 80 → 120，讓鑽石→傳說有耐久升級誘因

#### 戰鬥呈現：雙軌制（公開播報 + ephemeral 戰鬥介面）

**為什麼分軌**：既有 Phase 4 多人連打時公開洗版嚴重 — 玩家找不到自己的按鈕、戰敗訊息被全頻道看到丟臉、戰鬥日誌污染頻道。Phase H+ 從根本上解決：

- **公開精簡播報**：頻道有動態感、其他玩家看到誰在打、不洗版
- **ephemeral 戰鬥介面**：戰鬥結算、戰鬥日誌、操作按鈕全只給玩家自己看

##### 公開頻道訊息（一行精簡播報）

```
⚔️ 阿明 通過暗影狼 3F 古遺跡（8 回合）+ 鐵礦 ×3、+450 幣
```

| 情境 | 公開播報內容 |
|---|---|
| 勝利 1F-4F | `⚔️ XX 通過 [樓層名稱]（N 回合）+ 戰利品摘要` |
| 勝利 5F mini-BOSS | `🏆 XX 擊敗 [BOSS 名稱]！屠龍累積 X/10` |
| 失敗 | `💀 XX 在 [樓層] 倒下了（撐了 N 回合）` |
| 逃離 | `🏃 XX 從 [樓層] 撤退（剩 HP X%）` |
| 精英怪觸發 | `👹 XX 在 3F 遭遇精英怪！`（戰鬥前公開預告）|
| 罕見掉落 | `💎 XX 從 3F 挖到鑽石 ×3！`（罕見品公開）|

> 所有結果都公開播報 — 失敗 / 逃離也有戲劇性，能讓頻道看到「XX 死了沒帶藥水」「XX 被怪打哭逃跑」這種互動感。

##### 玩家 ephemeral 戰鬥介面（只玩家自己看）

**精簡模式（預設）**：

```
⚔️ 暗影狼 3F — 勝利！(8 回合)
HP 88→65/120、盾 49/50、體力 10→8、武器耐久 78→76
✨ 戰利品：鐵礦 ×3、+450 幣
[再戰一場][📜 查看戰鬥日誌][💊 補血][⚙️ 換樓層]
```

只 3 行：**結果 + 狀態 + 戰利品**，按鈕永遠在玩家自己畫面正下方。

**完整戰鬥日誌（點按鈕展開，仍 ephemeral）**：

```
🗡️ 第 1 回合：你揮砍 → 28 傷害
🦇 蝙蝠反咬 12 → 🛡️ 格擋！受 4 傷（HP 96/100、盾 49/50）
🗡️ 第 2 回合：你揮砍 → 25 傷害
🦇 蝙蝠中毒效果 → 5 傷（HP 90/100）
...（每回合一行）
```

##### ephemeral 訊息生命週期

| 階段 | 動作 |
|---|---|
| 玩家點 `/地下城` | 後端建立 ephemeral 訊息，含樓層選單 |
| 點 [3F 古遺跡] | `interaction.update()` 更新同一則訊息為戰鬥結算 |
| 點 [再戰一場] | 再次 update 同一則訊息（新戰鬥結果）|
| 點 [📜 查看戰鬥日誌] | 開新 ephemeral follow-up（完整日誌）|
| 玩家關閉 Discord | ephemeral 訊息消失，下次 `/地下城` 重啟 |

##### CLAUDE.md UX 規則 #7 的調整

原規則：「行動類（挖礦、釣魚、打工、購買）→ 公開訊息」

**新解讀**（適用於戰鬥型 / 多互動行動）：行動類**結果**公開精簡播報，**互動細節**仍 ephemeral（戰鬥介面、戰鬥日誌、按鈕）。

此原則順帶解決既有 Phase 4 多人連打洗版的問題。

#### 戰鬥日誌呈現規則

| 規則 | 說明 |
|---|---|
| 預設 | 精簡 3 行 + 「展開」按鈕 |
| 個人偏好 | `/地下城 設定 預設展開=true` 改為預設展開 |
| 每回合一行 | TextDisplay，最多 10 行詳述 |
| 超過 10 回合 | **中段自動摘要**：「第 5–N 回合：你穩定輸出，造成 X 傷害、受 Y 傷害」，保留前 5 + 後 5 回合詳述 |
| 顏色標記 | 暴擊紅 / 治癒綠 / 狀態紫 / 重傷閃爍 |
| 失敗時 | 預設**不展開**完整日誌（避免戰敗看大量負面訊息）|
| Container 上限 | 戰鬥日誌 Container 最多 40 個 components（Discord 限制 40，留 10 給結算 UI）|

#### 操作時間對比

| 模式 | 單場 | 連刷 10 場 |
|---|---|---|
| 既有 Phase 4（binary）| 8–10 秒 | 80–100 秒 |
| 新版精簡模式 | 12–15 秒 | 2–2.5 分鐘 |
| 新版精讀模式 | 60–90 秒 | 10–15 分鐘 |
| 5F mini-BOSS（精讀）| 90–120 秒 | — |

> 速刷玩家增加 **~30%** 時間（多看 HP / 盾 / 耐久 數字），但拿到顯著更多戰術資訊。

**ephemeral 統合戰報**：

#### 寵物協戰具體機制

| 階段 | 時機 |
|---|---|
| 寵物觸發判定 | **每回合玩家攻擊後**判定（怪物攻擊前）|
| 觸發成功 | 寵物追加一次行動（追擊 / 治癒 / 護盾），效果寫進戰鬥日誌 |
| 觸發失敗 | 不寫日誌（避免訊息冗長）|
| 戰鬥結束 | 寵物獲得 exp + 飢餓度扣減（協戰觸發過 −5、未觸發 −3）|
| 寵物 HP | 暫不引入（v1 不讓寵物受傷），未來可考慮 |

#### 狀態效果疊加規則

| 規則 | 說明 |
|---|---|
| 不同狀態 | 可同時生效（中毒 + 燃燒 + 麻痺都能堆）|
| 同狀態 refresh | 時長**重置為新時長**（不疊加），如玩家中毒剩 1 回合再被中毒 → 變回 3 回合 |
| 護甲互斥 | 玩家有「護甲」狀態時，怪物攻擊先扣護甲；狀態結束才扣 HP |
| 暴擊與狀態互動 | 暴擊穿透「護甲」50%、不影響其他狀態 |

#### 食物 buff 在 HP 戰鬥內的結算

| Buff 類型 | 結算方式 |
|---|---|
| 數值型（ATK / DEF / HP_max）| 戰前計算入 stats，整場有效 |
| 機率型（暴擊率）| 每回合判定，使用次數型 buff 整場扣 1 |
| 持續時間型 | 戰鬥不消耗時長（戰鬥可能僅幾秒內結算）|
