# 【PvP 新增企劃】—— 盜賊・通緝・賞金獵人系統

> 版本:v1.0　|　由 `PLAN_BRAINSTORM.md` D2「盜賊 / 偷竊 PvP」展開為完整規劃
> 對照 bibi-bot 現行系統(決鬥託管模式、銀行定存、財富稅、buffResolver、稱號、公會)設計,盡量複用不另起爐灶。

---

## 一、提案概述

把腦力激盪清單裡的「每日偷竊 → 成功偷幣 / 失敗被通緝」擴寫成一個**三方生態**:

- **小偷**:潛入他人錢包偷金幣,得手有賞、失手被通緝。
- **通緝犯**:失手後被公示,錢包透明,任人追捕;可自首洗白或潛伏躲過時效。
- **賞金獵人**:任何玩家都能追捕通緝犯,瓜分賞金,建立「社群自警」。

原始提案只有「偷 / 被通緝」兩步,體驗偏單薄且容易變成強者霸凌弱者。本企劃補上三個讓它**更有趣也更耐玩**的支柱:

1. **不是純骰運**——成功率由「小偷惡名 vs 目標防禦」動態決定,玩家能透過道具與行為經營自己的勝率。
2. **錢包 vs 銀行的攻防**——只偷得到**錢包**的錢,存進**定存**的錢絕對安全。一舉盤活現有銀行系統,把「該不該存」變成每天的真實抉擇。
3. **完整的追捕回路**——失手不是結束而是開始,通緝→追捕→自首/潛伏形成社群話題(「XX 又被通緝了!」「誰去把他抓回來」)。

### 設計原則(對齊 `CLAUDE.md`)

- **複用優先**:金流走 `grantCoins`、PvP 託管/抽水比照 `duelService`、Buff 走 `buffResolver`、每日重置用 luxon `Asia/Taipei`。
- **config 驅動**:所有數值(成功率、比例、冷卻、賞金公式、道具效果)放 `src/config/theft.json`。
- **防霸凌內建**:新手保護、低餘額免疫、同目標冷卻、每日上限、重複偷同人遞減——寫進 MVP,不是選配。
- **coin sink**:黑市抽成、保釋金、追捕賠款都是金幣回收出口,對抗通膨(與財富稅同向)。

## 二、名詞與角色

| 名詞 | 說明 |
|---|---|
| 🥷 惡名(notoriety) | 小偷的聲望值。得手 +、被抓 / 自首 −。越高→成功率略升,但**目標賞金與被追捕難度也一起升**,形成自我節制。 |
| 💰 錢包(wallet) | `userCoinsCollection.totalCoins`,唯一可被偷的資金池。 |
| 🏦 定存(deposit) | 現有銀行定期存款,**偷竊絕對碰不到**。鼓勵玩家把主要資產鎖進銀行。 |
| 🚨 通緝(wanted) | 偷竊失手後進入的狀態,列於 `/通緝榜`,錢包公開,可被任意玩家追捕。 |
| 🎯 賞金(bounty) | 通緝犯頭上的懸賞,由「系統底金 + 惡名加成 + 歷史贓款」組成,追捕成功者領走。 |
| 🕵️ 賞金獵人 | 執行 `/追捕` 的任何玩家,不需事前身分。 |

## 三、核心玩法

### 3-1. `/偷竊 @對象`(行動類・公開訊息)

> 公開訊息讓頻道看到動態(對齊 UX 檢查 #7:行動類公開)。

**前置檢查(任一不過→紅色 Container 錯誤訊息,對齊 UX #2)**:

1. **每日次數**:每人每日 `dailyLimit`(預設 **2** 次)。以當日(UTC+8)已完成的偷竊動作計。
2. **同目標冷卻**:對同一目標 `samePairCooldownMs`(預設 **12 小時**)內不可再偷(比照 `duelService` 的 pair cooldown)。
3. **自身狀態**:自己正在通緝中不可偷竊(先把自己的事處理完)。
4. **目標保護**(以下任一成立→不可偷,訊息明講原因):
   - 目標入服 / 首次活躍未滿 `newbieProtectDays`(預設 **7** 天)。
   - 目標錢包 < `minTargetWallet`(預設 **500** 幣)——沒油水,免得欺負窮人。
   - 目標持有生效中的 🐕「看門狗」防禦道具且尚未被消耗(見 §5)。
   - 目標當日「被偷次數」已達 `maxStolenPerDayPerTarget`(預設 **2**),當日不再受害。

**判定(非純亂數,對齊「更有趣」)**:

```
基礎成功率 baseRate(預設 0.55)
 + 惡名加成  min(notoriety × notorietyRatePer, notorietyRateCap)   // 老手更熟練,但有上限
 + 潛行道具  夜行衣 / 萬能鑰匙 提供的臨時加成(§5)
 − 目標防禦  保險箱 / 防狼警報器 提供的減值(§5)
 → clamp 到 [minRate 0.15, maxRate 0.85]  // 永遠留給雙方翻盤空間
```

加權隨機一擲定生死(複用既有 weighted random)。

**成功**:

- 偷走目標**錢包**的 `stealPct`(預設 **12%**),夾在 `[stealMin 100, stealMax 3000]` 幣之間。
- **黑市抽成** `blackMarketRakePct`(預設 **20%**)進系統(coin sink,`source: "steal_rake"`),小偷實得 80%。
- 目標損失走 `grantCoins(... source:"steal_loss")`,小偷所得走 `source:"steal_gain"`(皆 peer 類,不套倍率)。
- 惡名 +1。累積「贓款總額」(算入未來自己被追捕的賞金)。
- **成功訊息附快捷按鈕**(對齊 UX #3):`💰 把錢存進銀行`(直通存款,避免立刻被反偷) + `🥷 查看我的惡名`。
- 私訊 / ephemeral 提醒**被害者**:「你的錢包被 XX 偷走了 N 幣!」+ 按鈕 `🏦 快去存款` / `🔒 逛逛防身道具`。

**失敗**:

- **不損失金幣**(避免雙輸挫折),但**立即通緝**:寫入 `wantedListCollection`,錢包公示。
- 產生賞金(見 §4 公式),惡名 +2(失手更顯眼)。
- 若目標持有 🔔「防狼警報器」→ 觸發反噬:小偷額外賠 `alarmPenalty`(預設 **300** 幣,`source:"steal_alarm_penalty"` sink)給目標,警報器消耗 1 個。
- 公開訊息:紅色 Container「🚨 XX 偷竊失風,遭全鎮通緝!賞金 $Y」+ 按鈕 `🕵️ 我要追捕`。

### 3-2. `/通緝榜`(查詢類・ephemeral)

- 列出本伺服器目前所有通緝犯:名字、賞金、通緝到期時間、目前錢包(公示)。
- 每個通緝犯**正下方**接一排 ActionRow(對齊 UX #1:按鈕緊貼項目):`🕵️ 追捕` 按鈕。
- 超過 `列表上限` 時用分頁 / Select(對齊 UX #8:先算元件數,列表型優先 Select/分頁)。
- 零通緝犯時顯示 `-# 本鎮目前海清河晏,無人在逃。`

### 3-3. `/追捕 @通緝犯`(行動類・公開)

- 任何玩家(非通緝犯本人)可追捕。每日追捕次數上限 `huntDailyLimit`(預設 **3**)。
- 判定:`huntBaseRate`(預設 0.5) 依「追捕者攻擊力 vs 通緝犯攻擊力」微調(複用 `buffResolver.atkFromProfile`,比照決鬥計分),clamp `[0.2, 0.8]`。
- **成功**:
  - 賞金全額給追捕者(`source:"bounty_payout"`,peer/flat)。
  - 通緝犯額外賠 `caughtFinePct`(預設 **10%**)錢包當「贖罪金」,其中一半給追捕者、一半進系統 sink(`source:"bounty_fine"`)。
  - 通緝犯脫離通緝、惡名 −2。稱號檢查(賞金獵人)。
- **失敗**:通緝犯**成功逃脫**這一擊,追捕者今日該次數消耗;連續躲過到通緝時效則自動洗白(見 §4)。

### 3-4. `/自首`(行動類・ephemeral 起手,結果公開)

- 通緝犯主動繳 `bailCoins`(= 當前賞金 × `bailPct` 預設 **60%**,`source:"bail"` sink)換取立即解除通緝、惡名 −1。
- 好處:不用一直提心吊膽被追捕;壞處:要花錢。給玩家「花錢消災 vs 賭潛伏」的抉擇。

## 四、通緝 / 賞金 / 時效

**賞金公式**(通緝當下算一次,存進 `wantedListCollection`):

```
bounty = baseBounty(預設 500)
       + notoriety × bountyPerNotoriety(預設 50)
       + 該犯歷史累積贓款 × stolenBountyPct(預設 5%)
       → clamp [bountyMin 300, bountyMax 8000]
```

惡名越高、偷越多 → 賞金越肥 → 越多人想抓 → 形成「爬得越高摔得越重」的自然平衡。

**時效(潛伏)**:通緝維持 `wantedTtlHours`(預設 **48** 小時)。期間沒被抓到 → 自動洗白(cron 清理,比照 `expireDuel` 的逾時模式),惡名 −1,但**不退賞金**(賞金蒸發)。給通緝犯「低調潛伏熬過時效」的合法出路。

**惡名衰退**:每日重置時,當日無偷竊行為者惡名 −1(自然洗白,鼓勵金盆洗手),下限 0。走 compute 或每日 cron,不寫死(對齊 CLAUDE.md「加成動態換算」精神:惡名是狀態不是結果)。

## 五、防身 / 潛行道具(接 `shop` + `backpack`)

新增一組道具,讓攻防雙方都有可經營的策略(數值放 `theft.json`,道具本身走現有商店 / 背包系統):

| 道具 | 陣營 | 效果 | 設計意圖 |
|---|---|---|---|
| 🐕 看門狗 | 守 | 持有時**完全免疫**下一次偷竊(擋一次即消耗) | 花錢買一次絕對安全,適合大戶睡前防身 |
| 🔒 保險箱 | 守 | 被偷成功率 −`safeRate`(預設 0.2),持續 24h | 降低被盯上的機率,長效被動 |
| 🔔 防狼警報器 | 守 | 小偷失手時反噬罰款 +`alarmPenalty`,擋一次消耗 | 讓小偷不敢隨便試,懲罰型 |
| 🕶️ 夜行衣 | 攻 | 下一次偷竊成功率 +`cloakRate`(預設 0.15),用一次消耗 | 小偷的「進攻卡」 |
| 🗝️ 萬能鑰匙 | 攻 | 下一次偷竊無視目標保險箱減值,用一次消耗 | 破解守方 build 的剋制道具 |
| 💨 煙霧彈 | 攻 | 被追捕時擋一次追捕(必逃脫),消耗 | 通緝犯的保命符 |

> 這些道具是**存物品、不存加成結果**(對齊 CLAUDE.md):偷竊 / 被偷判定時才即時讀背包扣道具,不預先把加成寫進 profile。
> 全部 config 驅動,上線只要在 `shop.json` 掛販售、`theft.json` 定效果。名稱一律中文(對齊名稱表規則),同步 `bibi-website` 的 `botDefs.ts`。

## 八、平衡分析

- **金幣不憑空生成**:偷竊是**玩家間轉移**(zero-sum),再被黑市抽成 20%、保釋、贖罪金**淨回收**(sink)。整體對通膨是**收縮**的,方向與財富稅一致。
- **防霸凌四道閘**:新手保護 7 天、低餘額(<500)免疫、同目標 12h 冷卻、每日次數上限。強者無法無限碾壓弱者。
- **錢包/銀行抉擇**:偷竊只吃錢包 → 玩家為了安全會把錢存定存 → 定存鎖住流動性(現有機制)→ 錢包裡的活錢才是靶。銀行系統獲得**真實使用動機**,而非只是利息。
- **爬得高摔得重**:惡名↑ 成功率略升,但賞金↑、被追捕難度↑ → 自然收斂,不會出現「無敵大盜」。
- **失手不雙輸**:偷竊失敗不扣小偷的錢(只被通緝),降低嘗試門檻;真正的代價是「被抓要賠 + 保釋要花」,把懲罰後置到追捕階段,體驗更爽快、話題性更強。

## 十、待確認(不影響拍板)

1. 偷竊得手是否要對被害者發**私訊**還是只在頻道公開提醒(隱私 vs 話題性,傾向頻道公開 + 被害者 ephemeral 提醒各一)。
2. 惡名衰退用每日 cron 或 compute-on-read——若要嚴格遵守「不寫死」建議 compute-on-read,但惡名同時要當通緝賞金輸入,cron 每日結算較單純,兩者擇一。
3. 防身道具的定價需搭配現有 shop 經濟再抓一次(避免看門狗太便宜使偷竊系統整組失效)。
