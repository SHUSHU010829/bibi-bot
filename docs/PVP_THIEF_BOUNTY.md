## 一、提案概述

把腦力激盪清單裡的「每日偷竊 → 成功偷幣 / 失敗被通緝」擴寫成一個**三方生態**:

- **小偷**:潛入他人錢包偷金幣,得手有賞、失手被通緝。
- **通緝犯**:失手後被公示,錢包透明,任人追捕;可自首洗白或潛伏躲過時效。
- **賞金獵人**:任何玩家都能追捕通緝犯,瓜分賞金,建立「社群自警」。

原始提案只有「偷 / 被通緝」兩步,體驗偏單薄且容易變成強者霸凌弱者。本企劃補上三個讓它**更有趣也更耐玩**的支柱:

1. **不是純骰運**——成功率由「小偷惡名 vs 目標防禦」動態決定,玩家能透過道具與行為經營自己的勝率。
2. **錢包 vs 銀行的攻防**——只偷得到**錢包**的錢,存進**定存**的錢絕對安全。一舉盤活現有銀行系統,把「該不該存」變成每天的真實抉擇。
3. **完整的追捕回路**——失手不是結束而是開始,通緝→追捕→自首/潛伏形成社群話題(「XX 又被通緝了!」「誰去把他抓回來」)。

### 設計原則(對齊 `CLAUDE.md`)

- **複用優先**:金流走 `grantCoins`、PvP 託管/抽水比照 `duelService`、Buff 走 `buffResolver`、每日重置用 luxon `Asia/Taipei`。
- **config 驅動**:所有數值(成功率、比例、冷卻、賞金公式、道具效果)放 `src/config/theft.json`。
- **防霸凌內建**:新手保護、低餘額免疫、同目標冷卻、每日上限、重複偷同人遞減——寫進 MVP,不是選配。
- **coin sink**:黑市抽成、保釋金、追捕賠款都是金幣回收出口,對抗通膨(與財富稅同向)。

## 二、名詞與角色

| 名詞 | 說明 |
|---|---|
| 🥷 惡名(notoriety) | 小偷的聲望值。得手 +、被抓 / 自首 −。越高→成功率略升,但**目標賞金與被追捕難度也一起升**,形成自我節制。 |
| 💰 錢包(wallet) | `userCoinsCollection.totalCoins`,唯一可被偷的資金池。 |
| 🏦 定存(deposit) | 現有銀行定期存款,**偷竊絕對碰不到**。鼓勵玩家把主要資產鎖進銀行。 |
| 🚨 通緝(wanted) | 偷竊失手後進入的狀態,列於 `/通緝榜`,錢包公開,可被任意玩家追捕。 |
| 🎯 賞金(bounty) | 通緝犯頭上的懸賞,由「系統底金 + 惡名加成 + 歷史贓款」組成,追捕成功者領走。 |
| 🕵️ 賞金獵人 | 執行 `/追捕` 的任何玩家,不需事前身分。 |

## 三、核心玩法

### 3-1. `/偷竊 @對象`(行動類・**成功 ephemeral / 失敗公開**)

> 特殊處理:偷竊**得手僅小偷可見**(潛行,不驚動任何人),**失手才公開**(遭全鎮通緝的戲劇性)。這是對 UX #7「行動類公開」的刻意例外,理由見下方「成功」段。

> 數值採**折衷基準**(既非最嚴防霸凌、也非全放縱鼓勵互動),上線後看實際數據再調。各參數往哪個方向調的說明見 §八。

**前置檢查(任一不過→紅色 Container 錯誤訊息,對齊 UX #2)**:

1. **每日次數**:每人每日 `dailyLimit`(折衷基準 **3** 次)。以當日(UTC+8)已完成的偷竊動作計。
2. **同目標冷卻**:對同一目標 `samePairCooldownMs`(折衷基準 **8 小時**)內不可再偷(比照 `duelService` 的 pair cooldown)。
3. **自身狀態**:自己正在通緝中不可偷竊(先把自己的事處理完)。
4. **賞金本金門檻**:小偷**自己錢包**須 ≥ `bountyMin`(預設 **300** 幣)才能動手。理由——失風時賞金**從小偷錢包託管**(見 §4),若允許把錢全存銀行、錢包空空去偷,失手也沒錢可託管 = 零風險。此門檻堵住「銀行避險 + 無本偷竊」的漏洞,並呼應主題:**當賊也要先備妥失風的本錢**。訊息:「你的錢包不足以支付失風的賞金保證金,先賺點本錢或從銀行提領。」
5. **目標保護**(依序判定,任一成立→不可偷,訊息明講原因):
   - 目標入服 / 首次活躍未滿 `newbieProtectDays`(預設 **7** 天)。
   - 目標錢包 < `minTargetWallet`(預設 **500** 幣)——沒油水,免得欺負窮人。
   - 目標**當日已被成功偷 `maxStolenPerDayPerTarget` 次**(折衷基準 **3**),當日不再受害。此為**免費保護**(不需道具)。
   - 🐕「看門狗」**最後一道防線**:上面的免費保護都沒擋下、目標仍可被偷時,才消耗 1 隻看門狗擋下這次(所以看門狗不會被「反正今天已偷滿」的無效攻擊白白吃掉)。

**判定(非純亂數,對齊「更有趣」)**:

```
基礎成功率 baseRate(預設 0.55)
 + 惡名加成  min(notoriety × notorietyRatePer, notorietyRateCap)   // 老手更熟練,但有上限
 + 潛行道具  夜行衣 / 萬能鑰匙 提供的臨時加成(§5)
 − 目標防禦  保險箱 / 防狼警報器 提供的減值(§5)
 → clamp 到 [minRate 0.15, maxRate 0.85]  // 永遠留給雙方翻盤空間
```

加權隨機一擲定生死(複用既有 weighted random)。

**成功**:

- 偷走目標**錢包**的金額走**累進級距**(越後面的錢比例越低):0–5k 抽 12%、5k–30k 抽 8%、30k+ 抽 4%,下限 `stealMin 100`。
  - **單次上限用惡名解鎖**:`上限 = min(baseCap 3000 + 惡名 × capPerNotoriety 300, hardCap 12000)`。新手封在 3000,惡名越高偷得越多,惡名 30 解到 12000 頂。→ 大戶很香,但**只有資深慣竊刮得到大額**(新手盯鯨魚也只拿基礎額),自然防止新帳號一上來就獵鯨。
- **黑市抽成** `blackMarketRakePct`(預設 **20%**)進系統(coin sink,`source: "steal_rake"`),小偷實得 80%。
- 目標損失走 `grantCoins(... source:"steal_loss")`,小偷所得走 `source:"steal_gain"`(皆 peer 類,不套倍率)。
- 惡名 +1。累積「贓款總額」(算入未來自己被追捕的賞金)。
- **不通知被害者**:得手訊息**僅小偷自己可見(ephemeral)**,不在頻道公開、不私訊、不提醒受害者。神不知鬼不覺,被害者只能日後自己從 `/金幣紀錄` 察覺短少 → 製造「誰偷了我?」的懸疑與追查樂趣。
  - **這是對 UX #7 的刻意例外**:偷竊雖屬行動類,但成功結果走 ephemeral(潛行的核心體驗)。失敗才公開(見下)。
- **成功訊息附快捷按鈕**(對齊 UX #3):`💰 把錢存進銀行`(把贓款鎖進定存,避免反被偷) + `🥷 查看我的惡名`。

**失敗**:

- **不扣罰金**(對齊決策:失敗不扣錢只通緝),但**立即通緝**:寫入 `wantedListCollection`,錢包公示。
- **賞金從小偷錢包託管(escrow)**:通緝當下依 §4 公式算出賞金,並**從小偷錢包實扣該金額凍結**(`source:"bounty_escrow"` sink 側先扣;抓到 → 轉給獵人,潛伏成功 → 原額退回小偷)。真正的代價**後置到被抓那一刻**,失手當下不痛,被逮才痛——體驗爽快、話題性強。
  - 因前置 #4 已保證錢包 ≥ `bountyMin`,託管一定付得起;賞金公式上限也**夾在小偷錢包餘額內**(越有錢的慣犯賞金越肥,自然收斂)。
- 惡名 +2(失手更顯眼)。
- 若目標持有 🔔「防狼警報器」→ 觸發反噬:小偷額外賠 `alarmPenalty`(預設 **300** 幣,`source:"steal_alarm_penalty"` sink)給目標,警報器消耗 1 個。
- 公開訊息:紅色 Container「🚨 XX 偷竊失風,遭全鎮通緝!賞金 $Y」+ 按鈕 `🕵️ 我要追捕`。

### 3-2. `/通緝榜`(查詢類・ephemeral)

- 列出本伺服器目前所有通緝犯:名字、賞金、通緝到期時間、目前錢包(公示)。
- 每個通緝犯**正下方**接一排 ActionRow(對齊 UX #1:按鈕緊貼項目):`🕵️ 追捕` 按鈕。
- 超過 `列表上限` 時用分頁 / Select(對齊 UX #8:先算元件數,列表型優先 Select/分頁)。
- 零通緝犯時顯示 `-# 本鎮目前海清河晏,無人在逃。`

### 3-3. `/追捕 @通緝犯`(行動類・**結果私人**,成功才公開廣播)

- 追捕結果一律 **ephemeral**(只有追捕者看得到),避免頻道被「不在逃 / 慢了一步 / 讓他跑了」洗版;**只有成功逮捕**才把結果推到通緝廣播頻道(`announceChannelId`)。
- 任何玩家(非通緝犯本人)可追捕。每日追捕次數上限 `huntDailyLimit`(預設 **3**)。
- 判定:`huntBaseRate`(預設 0.5) 依「追捕者攻擊力 vs 通緝犯攻擊力」微調(複用 `buffResolver.atkFromProfile`,比照決鬥計分),clamp `[0.2, 0.8]`。
- **成功**:
  - **託管的賞金**全額發給追捕者(`source:"bounty_payout"`,peer)——錢是通緝當下就從小偷凍結的,系統不憑空產幣。
  - 通緝犯**再**賠 `caughtFinePct`(預設 **10%**)當下錢包當「贖罪金」,一半給追捕者、一半進系統 sink(`source:"bounty_fine"`)。
  - 通緝犯脫離通緝、惡名 −2。稱號檢查(賞金獵人)。
- **失敗(逃脫)**:通緝犯甩開這一擊,**躲起來進入冷卻**,期間**任何人都不能再追捕**他(存 `hunt_cooldown_until` 於通緝doc,重新通緝時清零);賞金續留託管;連續躲過到通緝時效則自動洗白(見 §4)。
  - **冷卻隨通緝犯惡名遞增**——越大尾躲越久:`min(base 30分 + 惡名 × 5分, max 3 小時)`。惡名 0→30 分、10→80 分、30↑→封頂 3 小時。

### 3-4. `/自首`(行動類・ephemeral 起手,結果公開)

- 通緝犯主動認罪:**沒收託管賞金的 `bailForfeitPct`(預設 60%)進系統 sink(`source:"bail"`),其餘退回小偷**,立即解除通緝、惡名 −1。
- 好處:不用一直提心吊膽被追捕、還能拿回部分託管金;壞處:要放棄大半賞金。給玩家「花錢消災 vs 賭潛伏熬過時效」的抉擇。

### 3-5. `/報案`(查詢類・ephemeral)

> 對齊決策:得手不通知被害者,但被害者可**花錢查兇手**。這是被害者唯一的反制入口,也多一個 coin sink。

- 被害者付 `detectiveFee`(預設 **500** 幣,`source:"detective_fee"` sink)委託偵探,調閱近 `investigateWindowHours`(預設 **24** 小時)內偷過自己的紀錄(查 `theftAttemptsCollection`)。
- 判定:每筆命中以 `investigateRate`(預設 **0.7**)機率查出兇手身分——**不保證**,保留潛行方一點運氣空間。
  - **查出** → ephemeral 告知兇手是誰、偷走多少;並附按鈕:若對方目前有把柄可**懸賞通緝**(進階,Phase 2)或直接 `🗡️ 找他決鬥`(串現有 `/決鬥`)討回公道。
  - **查無** → 「線索太少,查不出來…」(退還?→ 預設**不退**,委託本身就是消耗;可設 config `refundOnMiss`)。
- 平時(沒被偷)`/金幣紀錄` 只會看到匿名的 `遭竊 -N`,想知道是誰就得報案——把「被偷」變成一段可追查的懸疑,而不是單向挨打。

## 四、通緝 / 賞金 / 時效

**賞金公式**(通緝當下算一次,存進 `wantedListCollection`):

```
bounty = baseBounty(預設 500)
       + notoriety × bountyPerNotoriety(預設 50)
       + 該犯歷史累積贓款 × stolenBountyPct(預設 5%)
       → clamp [bountyMin 300, min(bountyMax 12000, 小偷當前錢包)]   // 賞金即託管金,不可超過小偷付得起的額度
```

賞金當下即**從小偷錢包實扣凍結**(escrow),故上限夾在其錢包餘額內。惡名越高、偷越多 → 賞金越肥 → 越多人想抓 → 形成「爬得越高摔得越重」的自然平衡。

**時效(潛伏)**:通緝維持 `wantedTtlHours`(預設 **24** 小時 / 一天)。期間沒被抓到 → 自動洗白(cron 清理,比照 `expireDuel` 的逾時模式),惡名 −1,**託管賞金原額退回小偷**(`source:"bounty_refund"`;賞金蒸發、沒人領到)。給通緝犯「低調潛伏熬過時效、拿回本金」的合法出路——呼應「失敗不扣錢」:只要沒被逮,最終不損失,唯一代價是這一天提心吊膽 + 惡名上升。

**失風追逃(章節式逃跑,通緝的前置關卡)**:偷竊失手**不會立刻上通緝榜**,而是先觸發一場「逃跑戲」——這是給新人更有臨場感的體驗,也讓失手不再是瞬間懲罰。失手當下錢包**不扣賞金**、狀態設 `fleeing`(不列 `/通緝榜`、不可被追捕),玩家在 ephemeral 訊息逐關選逃亡路線(`escapeRun.routes`:🌆 混入人群穩但慢 +1、🌫️ 鑽暗巷中庸 +2、🏙️ 飛簷走壁快但險 +3),每關依「已逃距離熱度 × 路線風險」決定被逮率,越往後越危險。

- **躲到 `distanceToClear` 終點 → 清白脫身**:狀態轉 `escaped`,**從未上通緝榜、賞金一毛沒扣**、神不知鬼不覺(不公開廣播,呼應偷竊的潛行主題)。
- **任一關被逮 → 才正式通緝**:此刻才 `bounty_escrow` 從錢包凍結賞金、狀態轉 `wanted`、時效由此刻起算,並公開通緝令(帶追捕鈕)+ 刷新看板,進入原本的追捕 / 自首 / 潛伏迴路。
- **放著不玩 → 逾時視同沒逃掉**:cron(`sweepFleeingTimeouts`)把逾時的 `fleeing` 一律送上通緝榜(同被逮處理),杜絕「不點就沒事」的規避。

實作:失手時 upsert `fleeing` doc(含 `flee.{distance,token,expires_at}` + 預算好的 bounty,但**尚未扣款**);`fleeStep` 用 `flee.token` compare-and-set 逐關推進防重複結算;被逮 / 逾時走共用的 `becomeWanted()`(此時才 escrow、clamp 在當前錢包內)。賞金只在「真的被通緝」時才凍結,清白脫身完全不動錢——比舊版「失手即扣即託管」對玩家更友善,也把追逃變成通緝的守門關卡。

**惡名衰退**:每日重置時,當日無偷竊行為者惡名 −1(自然洗白,鼓勵金盆洗手),下限 0。走 compute 或每日 cron,不寫死(對齊 CLAUDE.md「加成動態換算」精神:惡名是狀態不是結果)。

## 八、平衡分析

- **金幣不憑空生成**:偷竊是**玩家間轉移**(zero-sum),再被黑市抽成 20%、贖罪金、自首沒收、報案委託**淨回收**(sink)。**賞金也不是系統產幣**——它是通緝當下從小偷錢包託管來的。整體對通膨是**收縮**的,方向與財富稅一致。
- **防霸凌(折衷基準)**:新手保護 7 天、低餘額(<500)免疫、同目標 8h 冷卻、每日 3 次、同一人每日最多被偷 3 次。強者無法無限碾壓弱者;數值往「更嚴」調降次數/拉長冷卻,往「更活躍」則反之(見 §三 折衷說明)。
- **無本偷竊漏洞已堵**:因賞金從小偷錢包託管,前置 #4 要求「錢包 ≥ bountyMin 才能偷」,防止玩家把錢全存銀行後零風險亂偷。當賊要先備妥失風的本錢。
- **錢包/銀行抉擇**:偷竊只吃錢包 → 玩家為了安全會把錢存定存 → 定存鎖住流動性(現有機制)→ 錢包裡的活錢才是靶。銀行系統獲得**真實使用動機**,而非只是利息。
- **爬得高摔得重**:惡名↑ 成功率略升,但賞金↑(且賞金上限吃自己錢包)、被追捕難度↑ → 自然收斂,不會出現「無敵大盜」。
- **失手不雙輸**:偷竊失敗不扣小偷的罰金(對齊決策),真正代價後置——被抓才丟託管賞金 + 賠贖罪金;潛伏熬過 48h 則全額拿回。降低嘗試門檻、體驗爽快、話題性強。
